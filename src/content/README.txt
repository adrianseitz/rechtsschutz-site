Bewertungen (echte Kundenstimmen)
=================================
Trage hier nur echte, freigegebene Bewertungen ein. Erfundene oder
umformulierte Bewertungen sind unzulässig (UWG, Anforderungen an Werbung).

Format je Eintrag:
{
  "name": "Marina K.",          // Vorname + Initial, nur mit Einwilligung
  "rating": 5,                  // 1–5
  "text": "Originalzitat der Bewertung",
  "date": "2026-09-14",         // Datum der Bewertung
  "source": "google"            // "google" | "trustpilot" | "direkt"
}

Die Durchschnittsnote wird automatisch aus diesen Einträgen berechnet.
Ist die Liste leer, wird der Bereich nicht angezeigt.

Verlinkung zu deinen Profilen (optional, in .env):
NEXT_PUBLIC_GOOGLE_REVIEWS_URL=https://g.page/...
NEXT_PUBLIC_TRUSTPILOT_URL=https://de.trustpilot.com/review/...
